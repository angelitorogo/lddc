Cómo instalar la APK

Para instalar la app en tu dispositivo Android, sigue estos pasos:

  1. Descarga el archivo APK desde el botón “Descargar app para Android”.
  2. Abre el archivo descargado desde la notificación o desde la carpeta Descargas.
  3. Si Android te muestra un aviso de seguridad, permite la instalación desde orígenes desconocidos (solo para tu navegador o gestor de archivos).
  4. Confirma la instalación y espera a que el asistente termine.
  5. Una vez instalada, encontrarás la app en el lanzador de aplicaciones.
